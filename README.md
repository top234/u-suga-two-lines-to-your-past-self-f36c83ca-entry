Two lines to my past self. The first is a warning: don't pawn Grandpa's guitar for forty bucks on Main Street. The second is the reason it matters: years later, my daughter learns her first song on those same strings. One small decision, one instrument saved, one song passed down.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$OUTPUT_DIR` (default `/output`).
